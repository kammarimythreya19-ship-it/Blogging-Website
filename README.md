# Blogging-Website

A simple blogging website built with HTML, CSS and JavaScript where users can write and read blog posts.

## Features
- Clean and responsive layout
- Add and view blog posts
- Easy to customize

## Tech Stack
- HTML
- CSS
- JavaScript

## Getting Started
1. Clone the repository:
   git clone https://github.com/kammarimythreya19-ship-it/Blogging-Website.git
2. Open the project folder
3. Open `index.html` in your browser

## Project Structure
- `index.html` – page structure
- `style.css` – styling
- `script.js` – functionality
